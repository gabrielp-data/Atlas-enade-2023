Como ler este banco

  1. Tabelas (pasta Tables no DBeaver): os dados do INEP como vieram, com os códigos originais.
  2. Views _desc (pasta Views): os mesmos dados com uma coluna ds_ ao lado de cada código, já com o texto (ex.: tp_sexo = F → ds_tp_sexo = Feminino).
  3. inep_2023_categorias: o significado de qualquer código do banco.
  4. Regra para cruzar dados: sempre pelo curso (nu_ano, co_curso). Cada arquivo do INEP vem numa ordem diferente (LGPD), então a linha 1 de uma tabela não é o mesmo estudante da linha 1 de outra. A view inep_enade_2023_indicadores_curso já faz esse cruzamento por curso.

Ligações (chaves estrangeiras):

inep_censo_2023_ies (1 linha por IES) ▲ co_ies inep_enade_2023_cadastro_curso (1 linha por curso — tabela central) ▲ (nu_ano, co_curso) inep_enade_2023_curso (arq1) ┐ inep_enade_2023_aluno_* (arq2 a arq14) ┘ 1 linha por estudante
